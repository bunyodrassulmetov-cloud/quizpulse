# QuizPulse — живая онлайн-викторина

Прототип сервиса живых викторин: ведущий выводит вопросы на большой экран (или в демонстрацию экрана в Zoom/Meet), а участники подключаются по **QR-коду или PIN** и отвечают со своих телефонов в реальном времени.

## Возможности

**Языки интерфейса:** русский, казахский (кириллица) и узбекский (латиница) — переключатель «Рус / Қаз / O'zb» в шапке у ведущего и у участника; язык телефона определяется автоматически, его можно задать ссылкой `?lang=kk` / `?lang=uz`. Переводы интерфейса — `public/i18n.js`.

**Вопросы и ответы тоже на выбранном языке:** у вопроса есть основной текст и переводы; сервер отправляет каждому участнику вопросы на *его* языке, а экран ведущего — на языке ведущего (в одной игре могут участвовать люди с разными языками). Все встроенные викторины переведены на казахский и узбекский (`public/quiz-i18n.js`). В редакторе есть вкладки «Язык вопросов: Рус / Қаз / O'zb» — основной язык отмечен точкой, незаполненный перевод показывается на основном языке.

**Ведущий** (`/host`)
- Библиотека викторин (хранится в браузере), импорт/экспорт JSON, копирование. Встроенные викторины: «Ислам в фотографиях» (все 12 вопросов — с фото), «Жизнеописание Пророка ﷺ», «Таухид — единобожие», «Коран и суры», «Удивительный мир: загадки и факты», «Ислам: вопросы среднего уровня», «Разминка: общая эрудиция». В первых четырёх около 40% вопросов — с картинкой (например, часы → сура «Аль-Аср»).
- Галерея фотографий (`public/img/photo/*.jpg`, Wikimedia Commons, свободные лицензии) — кнопка «Выбрать из галереи» в редакторе; можно указать и свою ссылку на картинку. Авторы и лицензии — на странице `/credits`.
- Редактор: вопросы с 2–4 вариантами (можно несколько правильных), «Верно/Неверно», таймер 5–120 сек, стандартные / двойные / нулевые очки, картинка по ссылке.
- Комната с 6-значным PIN и QR-кодом, список участников в реальном времени, удаление участника кликом, «Закрыть вход».
- Ход игры: показ вопроса (с картинкой, если есть) → приём ответов с таймером и счётчиком ответивших → диаграмма ответов и правильный ответ → таблица лидеров с изменением мест → пьедестал.
- Пьедестал: барабанная дробь → 3 место, дробь → 2 место, долгая дробь → победитель с рыком льва, лучами и конфетти. Телефоны участников из тройки узнают своё место одновременно с экраном. Есть кнопка «Пропустить анимацию».
- Итоги: таблица всех результатов и выгрузка в CSV (открывается в Excel).
- Настройки запуска: показывать вопрос на телефонах (для онлайн-формата), перемешать вопросы, звук для победителя (рык льва или аплодисменты и салют).
- Горячие клавиши: пробел / → — дальше. Кнопка полноэкранного режима.

**Участник** (`/` или `/join?pin=…` — сюда ведёт QR-код)
- Вход по PIN и имени (проверка уникальности). Аватар — цветной кружок с инициалами.
- Кнопки ответов, таймер, мгновенный отклик «Ответ принят».
- После вопроса: верно/неверно, полученные очки, серия правильных ответов, место и отставание от соседа выше.
- Финальное место. Переподключение: если телефон заблокировался или страница перезагрузилась — участник возвращается в игру со своими очками.

**Звуки** — без музыки. Во время игры звучат природные и бытовые звуки, которые синтезируются прямо в браузере: журчание ручья и пение птиц в лобби, порыв ветра при появлении вопроса, тиканье часов во время ответа и сердцебиение в последние 5 секунд, капля воды на каждый пришедший ответ, стук по дереву по окончании времени, всплеск при показе результатов, «дождь из капель» и птицы после объявления победителя. На пьедестале — настоящие записи с Wikimedia Commons: барабанная дробь и удар (CC0), для победителя — рык дикого льва (CC BY 4.0) или аплодисменты с салютом (общественное достояние), по выбору ведущего, файлы в `public/audio/`. Если запись не загрузилась, звучит синтезированный вариант. На телефонах: капля при нажатии, звуки «верно/неверно», итог. Звук отключается кнопкой с динамиком (у ведущего — вверху, у участника — внизу). Код звуков — `public/sounds.js`.

**Очки:** за правильный ответ от 1000 (мгновенно) до 500 (в последнюю секунду), ×2 для «двойных» вопросов, плюс бонус за серию (+100 за каждый правильный ответ подряд, до +500).

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000/host` — это экран ведущего. Участники в той же Wi-Fi сети сканируют QR-код: сервер сам подставляет в него IP-адрес компьютера в локальной сети (адрес виден в консоли при запуске).

## Игра через интернет (участники где угодно)

Чтобы QR-код работал не только в вашей Wi-Fi сети, приложение должно быть доступно по публичному адресу.

**Быстро, без регистрации — туннель** (пока открыт терминал):
```bash
npm start
# в другом терминале:
npx cloudflared tunnel --url http://localhost:3000
```
Откройте выданный адрес `https://….trycloudflare.com/host` — QR-код автоматически будет вести на этот адрес.

**Постоянно и бесплатно — Render** (render.com):
1. Войдите на render.com через GitHub.
2. New → Web Service → выберите этот репозиторий.
3. Build Command: `npm install`, Start Command: `npm start`, Instance Type: **Free** → Deploy.
4. Через 3–5 минут сайт будет доступен по адресу `https://<имя>.onrender.com`, ведущий — `/host`.

Либо New → Blueprint: настройки возьмутся из `render.yaml`. Бесплатный сервер засыпает после 15 минут без посетителей и просыпается примерно за минуту — откройте `/host` заранее. Публичный адрес для QR-кода подставляется автоматически.

**На любом другом хостинге** Node.js с поддержкой WebSocket (Railway, Fly.io, VPS):
- команда сборки: `npm install`, команда запуска: `npm start`;
- порт берётся из переменной `PORT`;
- при желании задайте `PUBLIC_URL=https://ваш-домен` — он попадёт в QR-код.

Адрес в QR-коде также можно поменять прямо в лобби кнопкой «Изменить адрес».

> Vercel/Netlify в бесплатном режиме не подходят: им нужны постоянные WebSocket-соединения.

## Устройство

```
server.js        — Express + Socket.IO, раздача страниц, генерация QR (/api/qr)
src/game.js      — логика комнаты: фазы игры, таймер на сервере, подсчёт очков, рейтинг
public/host.*    — экран ведущего (библиотека, редактор, проведение игры)
public/index.html, play.js — экран участника
public/sounds.js — звуки (Web Audio API, без музыки)
public/common.js, styles.css — общие утилиты и стили
```

Состояние игры хранится в памяти сервера (прототип): при перезапуске сервера текущие игры сбрасываются. Таймер и приём ответов контролирует сервер, поэтому опоздавший ответ не засчитается, а клиент не может подделать время.

## Формат JSON викторины

```json
{
  "title": "Моя викторина",
  "questions": [
    { "type": "quiz", "text": "2 + 2 = ?", "answers": ["3", "4", "5", "22"], "correct": [1], "timeLimit": 20, "points": 1, "image": "" },
    { "type": "truefalse", "text": "Земля круглая", "correct": [0], "timeLimit": 10, "points": 2 }
  ]
}
```

## Что можно добавить дальше

- Хранение викторин и результатов в базе данных, аккаунты ведущих.
- Командный режим, вопросы с вводом ответа, опросы без правильного ответа.
- Звуки и музыка в лобби, загрузка картинок файлом.
- Масштабирование на несколько серверов (Redis-адаптер Socket.IO).
